# 運営編集コンテンツ

- `rules.ts`: 基本ルール・用語。本文変更時に出典と `RULES_CHECKED_ON` を確認する。
- `tournaments.ts`: 確認済みの一部大会。公式の開催日・会場を照合し、`source` と `checkedOn` を大会単位で記録する。シーズン名と開催年は異なる場合があるため、日付は実際の開催年で記載する。
- `places.ts`: 公式店舗検索への案内。外部検索の仕様変更やリンク切れを確認し、`PLACES_CHECKED_ON` を更新する。

日付は `YYYY-MM-DD`。大会は日本時間の今日以降を初期表示し、開催日経過分もフィルターで閲覧できる。大会の中止や受付状況を日付から推測しない。

大会追加後は `pnpm test` と `pnpm run typecheck` を実行する。公開前および大会日程の変更発表時に公式情報を再確認する。初期収録は2026年11月25日に公式サイトで確認した8大会で、網羅的な一覧ではない。

選手紹介、口コミ・コメントなどの新しい自由記述投稿は扱わない。外部記事・写真の転載や自動収集は行わず、独自の要約と公式リンクを掲載する。
